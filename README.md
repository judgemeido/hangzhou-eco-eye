# 火眼金睛 · 杭州生态识别小游戏

一个纯前端静态网页小游戏：在 15 秒限时内认出杭州本地的动物与植物，收集生态图鉴、累计生态积分。全部图片与数据均已本地化，开箱即玩，无需构建步骤。

## 玩法
- 从样本里随机抽题，限时 15 秒判断图中物种。
- 答对加分（含速度加成、首次收录奖励），答错或超时扣分。
- 收录过的物种会进入生态档案图鉴。
- 胜负判定始终以样本的真实物种为准。

## 本地运行
仓库是纯静态页面，直接用浏览器打开 `index.html` 即可游玩。

若需要「大模型参考校验」功能（见下），请用附带的本地服务器启动，以便走同源代理绕过跨域限制：

```bash
node tools/serve.mjs
# 然后打开 http://localhost:8765
```

## 可选：接入大模型做参考校验
游戏内置一个可选的「大模型校验」功能——识别闯关时，把样本图发给你配置的多模态大模型做一次**参考校验**，仅作展示参考，**不影响游戏胜负判定**（胜负永远以样本真实物种为准）。

出于安全考虑，本仓库**不内置任何 API Key**。如需启用：

1. 用 `node tools/serve.mjs` 启动本地服务器并访问 `http://localhost:8765`。
2. 在游戏中按 `Ctrl+8` 打开设置面板。
3. 选择或新增一个供应商，填入 Base URL、API 格式（OpenAI 兼容 / Anthropic / Gemini）、端点路径、**你自己的 API Key** 与模型名，点「测试」确认连通后保存。
4. 选中该模型为当前引擎即可。

未配置 Key 或连接失败时，校验功能会**静默跳过**，不影响正常游玩。

## 目录结构
```
index.html        入口页面
css/style.css      样式
js/data.js         物种数据
js/images.js       本地图片映射
js/ai.js           识别 / 大模型配置引擎
js/game.js         游戏逻辑与界面
assets/img/        本地物种图片
tools/serve.mjs    本地静态服务器（含同源代理）
```

## 说明
- 纯 HTML / CSS / 原生 JS，无依赖、无构建。
- 存档与配置保存在浏览器 localStorage。
